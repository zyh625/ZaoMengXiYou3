# 无双、霸体与黑色残影

四角色预制体在 `Assets/Projects/Prefabs/Character`，已经填写下列默认值。

| 组件字段 | 用途 | 默认值 |
| --- | --- | --- |
| `PlayerBoost.moveMultiplier` | 四人的走路、跑步和空中水平移动倍率 | 1.3，即加速30% |
| `PlayerBoost.wukongCriticalChance` | 悟空额外暴击概率 | 0.3，即增加30个百分点 |
| `PlayerBoost.tangAttackMultiplier` | 唐僧攻击倍率 | 1.2，即增加20% |
| `PlayerBoost.bajieDamageMultiplier` | 八戒受到的伤害倍率 | 0.5，即额外减伤50%，与其他来源叠乘 |
| `PlayerBoost.shaSuperArmor` | 沙僧无双的普通霸体 | 开启 |
| `PlayerCombat.criticalChance` | 角色的基础暴击概率 | 0 |
| `PlayerCombat.criticalMultiplier` | 暴击伤害倍率 | 2 |

每个角色的这些字段都可以分别调整。固定轨迹技能自身的专属位移参数继续由角色的 Movement 控制。

普攻、组合技和技能的实际命中统一由 `PlayerCombat.CreateAttackDamage()` 计算攻击倍率与一次暴击。中毒的周期伤害和反伤不重新判暴击。无双结束只移除自己的移速、攻击、暴击、减伤或霸体来源；其他技能提供的增益继续保留。无双期间原有气力锁定规则保留。

普通霸体仍扣血，但不产生普通受击硬直、击退、击飞或晕眩；冰冻、抓取、携带和吸附属于强控，霸体不能免疫。新控制效果使用 `Health.CanReceiveControl(ControlStrength.Ordinary/Strong)` 判断，无敌仍拒绝控制。满能量时，受击或冰冻中也可以用空格开启无双，开启瞬间驱散现有异常；之后再次施加的异常按各自规则处理。

未来新增异常状态接入 `Health.DebuffsCleared`，在回调中清除自己的计时、表现、属性来源和位置锁，并在停用时退订。统一驱散入口为 `Health.ClearDebuffs()`，不需要在 `PlayerBoost` 中逐个增加状态判断。

黑色残影由角色根节点上的 `ActorBoostTrail` 控制，四个角色的本体 SpriteRenderer 和残影材质均已填写。仅在无双开启且实际移动时，每个渲染帧留下当前精灵的快照，包括当时的动作、朝向、位置、旋转和缩放；快照留在世界坐标中，不再随人物改变。静止、顶墙和暂停时不生成新残影。

可调参数：`afterimageDuration` 默认为 0.2 秒，`trailColor` 默认为黑色、透明度 0.16，以每秒 60 帧为参照；更高帧率会按每帧时长降低单张残影透明度，避免残影数量增加后叠得过黑，低帧率也不会使单张残影深于配置值。`minimumMoveSpeed` 默认为每秒 0.03 单位以过滤接触地面产生的微小抖动，`sortingOffset` 默认为 -1，排在人物后方。残影线性淡出，暂停时淡出计时暂停。正常结束无双后，最后的残影仍完成淡出；死亡、停用和换人会立即清空。

残影共用 `Assets/Projects/Resources/Effects/BlackBoostAfterimage.mat`，采用项目现有 URP 的 Sprite-Unlit-Default 着色器，以精灵的透明轮廓渲染淡黑剪影，不替换角色原材质，也不复制人物描边。每个角色首次开启时预热 16 张残影，数量不足时自动扩容，淡出后归还复用，不逐帧销毁对象。

以后给敌人挂 `ActorBoostTrail`，在强化开始时调用 `SetActive(true)`，结束时调用 `SetActive(false)` 即可；本体引用与材质留空时会自动查找，特殊敌人也可以显式填写。旧白色流光资源已不再被此组件使用。
