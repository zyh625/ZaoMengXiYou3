## 存档兼容

- `SaveData.rebirth` 默认 0；旧 JSON 缺少字段时为 0，负值经 `Normalize` 纠正为 0。轮回次数可继续累计，只有难度计算封顶 10。
- `GameSession.Rebirth` 读取当前已选档的数据；未选档返回 0。地图和六个存档槽显示各自的轮回数，空槽显示“第 0 轮回”。
- `unlocked` 是四角色位掩码。旧档根据最高可进入关卡及已有角色等级、经验、技能记录补齐解锁，不清除养成数据；已轮回存档保留四人。
- 继续使用原有 JSON、临时文件替换与备份机制，没有新增另一套写盘流程。测试存档均在独立验证工程的 `output` 内，未操作正式玩家存档。
- Boss 金币仍遵循原有“每档每关首杀”规则；轮回不会清空 `defeatedBossLevels`。表中的 Boss 金币比较是符合首杀条件时的金额。

## 轮回公式

令 `N = Clamp(rebirth, 0, 10)`。只在正式第 1～6 关应用以下倍率。

| 项目 | 公式 | N=0 | N=1 | N=10 / 11 |
| --- | --- | --- | --- | --- |
| 敌人 HP | `1 + 0.35N` | 1.00 | 1.35 | 4.50 |
| 敌人伤害 | `1 + 0.15N` | 1.00 | 1.15 | 2.50 |
| 金币金额 | `1 + 0.25N` | 1.00 | 1.25 | 3.50 |
| 经验 | `1 + 0.20N` | 1.00 | 1.20 | 3.00 |
| 小怪数量 | `1 + 0.08N` | 1.00 | 1.08 | 1.80 |
| 攻击冷却 | `Max(0.75, 1 - 0.03N)` | 1.00 | 0.97 | 0.75 |
| 追击移速 | `1 + 0.02N` | 1.00 | 1.02 | 1.20 |
| 刷怪间隔 | `Max(0.70, 1 - 0.03N)` | 1.00 | 0.97 | 0.70 |
| 同屏小怪上限增加 | `Min(1, Ceil(0.1N))` | 0 | 1 | 1 |

数量必须是整数：先对整关基础总数乘倍率并向上取整，再用最大余数法分配各波左右数量，保留原本为 0 的出生侧。这样不会因每项分别 `Ceil` 而额外放大数量。金币最终金额四舍五入为整数，掉落概率不变；经验保留浮点值。

## 应用位置

| 位置 | 实现与不重复乘算的保证 |
| --- | --- |
| `Core/RebirthScaling.cs` | 统一公式、有效轮回封顶、场景范围和数量分配；训练场、菜单、第 7～9 关返回基础倍率。 |
| `Level/StageEnemyManager.ApplyStatScales` | 每次出池前从预制体基础 HP 计算，叠乘普通/召唤倍率和轮回倍率；伤害通过 `SetExternalDamageScale` 设置。 |
| `Level/LevelEnemyManager` | 基础创建入口覆盖旧通用池路径和 Boss，同样使用预制体基础值；实际启用后血量回满。 |
| `Level/LevelManager` | 初始化时复制并缩放运行时左右数量数组；出生、结束条件和 `BattleRun.SetWave` 共用这份数量。刷怪间隔和同屏上限读取时计算，不改场景配置值。 |
| `Enemy/EnemyCombat` | 检查攻击请求时叠乘冷却倍率；愤怒等原有来源继续独立计算。 |
| 独立技能冷却 | 覆盖 PurpleRanged、BlueWheel、RedBoom、GreenSummon 及 East/South/West/North 的独立冷却和 Boss 公共攻击间隔；不压缩预警、持续伤害周期、护盾计时及玩家输出窗口。 |
| `Enemy/EnemyMovement` | 统一追击入口读取移速倍率，基础移速、减速和愤怒配置不被改写。 |
| `Gold/GoldManager` | 每次战斗保存倍率快照，掉落金额缩放一次，完整拾取后入账。 |
| `Enemy/EnemyRewards` | 每次真实死亡只结算一次缩放后的经验；训练实例不发奖励。 |

所有敌人和 Boss 预制体均保留原始数值，没有创建轮回预制体变体。
