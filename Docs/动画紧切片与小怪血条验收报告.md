# 动画紧切片与小怪血条验收报告

日期：2026-11-04。

## 完成结果

- 检查全部 131 个预制体引用的动画资源：358 张 Multiple 图集、5,381 个 Sprite，另有 16 张已独立切好的单帧特效。16 张单帧特效已经紧贴内容，无需改动。
- 收紧 4,499 个过大切片；5,362 个非空 Sprite 最终均恰好包住原切片中的所有非透明像素。所有 PNG 像素均保持原样，没有重绘、重采样或删除素材。
- 修改 316 份图片 meta。切片矩形总面积从 457,948,920 降至 282,883,076 像素，减少 38.23%。这是切片矩形面积变化，源图集纹理尺寸不变。
- 角色、Boss、特效的帧名、Sprite ID、数组顺序、fps 和循环设置保持不变。缩小矩形时同步换算 pivot，保留动画原有的逻辑定位；部分跳跃/受击帧的 pivot 会在矩形外，这是保留原动作位移所必需的，不应直接改回中心。
- 对明显存在整体绘制比例差异的赤链、广目天王、鸣曜星鸮，共 16 套动作调整导入 PPU，以统一游戏内本体大小。武器伸展、展翅、蹲伏、倒地、特效扩散不按整体轮廓强行拉齐。其余动作已逐角色预览核对，保留原本接近一致的绘制比例。
- 校验 31 个角色/敌人/Boss 的本体 BoxCollider2D：只初步调整纵向偏移，使下沿接近 Idle 可见内容的脚底中位线；宽高与攻击/检查箱不变。悬浮单位保留悬浮姿态，不将角色图片拉到地面。
- 当前正式使用的全部 19 种小怪都有独立血条。新增 13 套 Canvas/blood；保留原有 6 套样式，并纠正其中 3 种小怪血条误挂在攻击/检查子物体上的问题，统一绑定本体 Health。Boss 保留专属血条。

## 后续调整位置

- 血条布局：各小怪预制体的 `Canvas` 与 `Canvas/blood` RectTransform，可以直接改位置、宽高、缩放。
- 血条美术：`Canvas/blood` 的 Image → Source Image / Color。保持 Image.Type=Filled、Horizontal、Origin=Left。布局和 Sprite 不会被运行时代码覆写。
- 血条时长：同名 `Assets/Projects/Resources/Balance/Enemies/<名称>.asset` → 根节点 EnemyHealthBar → seeDuration / fadeDuration。它们是运行时的实际数值来源。
- 本体碰撞箱：根节点 BoxCollider2D，直接在预制体上修改 Size / Offset 即可生效。（2026-11-06 起数值资产不再保存碰撞箱，原先的 `UnityEngine.BoxCollider2D` 组已全部移除。）
- 绘制大小：Texture Importer 的 Pixels Per Unit；数值越大，游戏内显示越小。本次对明显不一致动作的调整如下，其余资源保留原 PPU。精细的头部/肢体变形属于原画差异，紧切片不会重绘这些差异。
