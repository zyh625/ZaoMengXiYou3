# 运行时训练场验收报告

日期：2026-11-01。Unity 6000.4.9f1 / 2D / C# / URP。

入口：MapScene 右下角独立的 **训练场 / TRAINING** 按钮；退出返回 MapScene。可直接打开 `Assets/Projects/Scenes/Training/TrainingScene.unity` 运行，也已在正式 Build Settings 末尾启用，不进入关卡编号或解锁数组。

## 场景、目录与操作

独立训练场包含 96 单位平地、两侧物理边界、Global Light2D、现有 CameraRig 和 PlayerSystem 的场景实例，以及 TrainingManager、独立训练 HUD 和一套 Input System UI EventSystem。没有正式 LevelManager、波次、奖励或胜败结算组件。CameraFocus 按当前角色和当前目标取镜头中心，切人/换敌人后立即使用新引用。

地图入口在原 Canvas 下新增独立 Button，并直接绑定 TrainingEntry.OpenTraining；Map.EnterLevel、关卡按钮数组、解锁判断和存档按钮均保持原样。Build Settings 只在末尾追加 TrainingScene，之前所有条目的路径、启用状态和索引均保持不变。本次添加的是独立训练入口。

敌人目录：`Assets/Projects/Resources/Training/TrainingEnemyCatalog.asset`，资源路径 `Training/TrainingEnemyCatalog`。初始包含：Wolf、Tiger、PurpleHeavenly、PurpleRanged、BlueShield、BlueWheel、RedChain、RedBoom、TitanSpirit、EastKing、SouthKing、WestKing、NorthKing、GreenHammer、GreenSummon，共 **15 类**。之后只需编辑该资产的 Entries，不需要改运行时代码；初始化工具在目录已存在时不会重置用户内容。

使用 PREVIOUS / NEXT 切换敌人；切换先解绑伤害事件、停用并销毁原目标及旧技能效果，下一帧生成新目标，避免旧对象池与新对象混用。统计随新目标重置。角色仍使用原有操作、Q/E 四人切换和 U/I/O 技能，训练角色技能默认全部临时学习至 1 级。

## 训练开关与敌人模式

| 控件 | 行为 |
| --- | --- |
| INFINITE MP / VIGOR | 默认开启；TrySpendMana、TrySpendVigor、DrainVigor 都成功且不扣费；关闭恢复原费用、不足判定和普通无双规则 |
| NO SKILL COOLDOWN | 默认关闭；开启立即清除已有技能冷却，新技能冷却为 0；关闭后新释放技能恢复配置中的冷却，不绕过技能正在施放等原有状态限制 |
| NO HP LOSS | 默认开启；免扣血，保留普通受击、击退、命中与附加效果，适合观察手感；关闭立即恢复普通伤害。没有使用会拒绝整次命中的常规无敌来源 |
| DUMMY MIN HP = 1 | 默认开启，仅木桩模式生效；血量最低为 1，仍播放受击并持续报告用于统计的伤害；关闭可正常死亡 |
| COMBAT | 完整 AI、走动、转向、技能、受击与死亡 |
| DUMMY | 禁止走动、出招与转向；暂停 Combat 并由 Controller 的训练分支保留受击/死亡动画；锁住本体位置，清理旧技能、控制和临时状态 |
| RESPAWN (2 sec) | 完整 AI；死亡事件之后满 2 秒，原位置以同一个对象满血复活；不重复 Instantiate，开始新一轮统计 |
| AI PAUSED | 与木桩 / 战斗模式切换使用同一入口 |
| HITBOXES | 红色显示当前有效攻击箱，青色显示检查箱；仅在训练场存在 |
| RESET STATISTICS | 仅清空本目标统计，不重置 HP |
| RESTART TARGET | 重新生成当前选择目标并清空统计 |
| RETURN TO MAP | 结束训练并回地图，不结算、不保存 |

四角色都使用 PlayerManager 的原有切换流程；无限资源、无冷却与免扣血设置在切换后继续生效。关闭免扣血后玩家死亡也只在训练场两秒复活，不进入 DefeatScene。Boss 场地边界通过已有 IEnemyArenaBounds 接口绑定；持国天王召唤由训练管理器的独立 LevelEnemyManager 适配处理，最多同时两只，使用目录中标记的 summonFallback，训练中不调用正式关卡生成器。

目标切换、模式切换会清理训练场临时世界效果和召唤物；角色技能仍使用 PlayerManager 的原对象池。复活等待期间切换目标也已覆盖，旧复活流程不会重新激活或重置另一个新目标。

## 核心数据面板

右上角使用 TextMeshPro，约每 0.1 秒刷新；底部另显示当前角色、HP/MP/气力和技能剩余冷却。开发面板采用英文指标标签，以兼容项目现有 TMP 字体；中文地图入口优先使用系统中文字体，没有相应字体时显示 TRAINING。

| 标签 | 定义 |
| --- | --- |
| DPS (last 3s) | 当前游戏时间前 3 秒内有效伤害总和 / 3，固定窗口，不使用自第一次命中的平均值 |
| Total damage | 当前目标本次生命/测试的有效伤害累计 |
| Hits | 有效玩家主动伤害命中事件数，同一事件只累计一次 |
| Critical hits / Critical rate | 实际暴击事件数及 暴击数 / 命中数 |
| Max hit | 单次最高有效伤害 |
| Time to kill | 第一次有效玩家命中到目标 Died 的游戏时间，未击杀显示 -- |
| Target HP | 当前目标真实血量与上限 |

监听目标 Health.DamageReceived / Died。必须具有 PlayerController 来源，并剔除 IsReflected 和 IsPeriodic；召唤物及其他敌人的伤害不进入当前主目标面板。DamageInfo 新增默认 false 的只读 IsCritical 元数据，在 PlayerCombat 原来的那一次暴击随机判定中记录结果，没有再次投掷或根据伤害大小猜测。

普通战斗按实际失血统计，致死过量伤害按 Health 的实际扣血截断。无限木桩到 1 血后，使用同一 Health 管线计算出的、经过减伤/易伤而未受 1 血下限截断的模拟伤害，确保无限木桩仍能测 DPS；HP、动画和命中反馈仍来自真实目标。反伤、毒等周期伤害在两种口径下都排除。

三秒窗口使用预分配 8192 条循环缓冲；绘制模块缓存 Collider / LineRenderer，每帧只更新已有顶点。新判定体仅在调试开启时每 0.5 秒登记一次，逐帧绘制段不创建临时数组或集合。

## 存档、奖励与正式规则隔离

TrainingSession 在场景角色创建前开启。四份 PlayerData 为独立内存对象，PlayerResources 直接绑定它们；GameSession.data 保持原引用，角色等级、技能、经验不从已选档读取。进入场景不调用存档 Load/Save，也没有金币 BeginRun。

训练期 SaveSystem 的读取、保存、删除入口在访问文件前返回，并记录阻止次数。敌人实例的 EnemyRewards 在激活前关闭，奖励入口另有训练期保护，杜绝经验、金币及 Boss 首杀奖励。BattleRun 在训练中仅开放既有技能/投射物运行所需的战斗许可，Begin、伤害/击杀/波次统计、角色时间与 Finish 均不写入正式统计，也不覆盖上次正式结果。训练场没有胜败场景或解锁调用。

退出时角色、目标、池与调试绘制随场景卸载；TrainingSession 关闭，返回地图继续使用原来的会话和选档。公共扩展均为默认关闭的运行期开关，未加到存档字段或正式人物/敌人预制体。GameSession、SaveData 和正式关卡生成脚本未修改。
