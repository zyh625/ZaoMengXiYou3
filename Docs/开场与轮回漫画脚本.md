# 开场与轮回漫画

天庭向来以帝印颁发护世敕令。敕令随天钟传遍各重天，守将闻钟便知该往哪里巡守。黑衣人趁天钟将响，用一枚刻有三道朱痕的铜印篡改敕令。黑印落在众将身上，将守卫人间的命令扭成了镇压人间。天将下界封路，村民四散，附近的狼群也趁乱进了村。

师徒四人救人时，悟空发现天将身上有被黑线牵引的印记。唐僧试着斩断黑线，天将便恢复了神志。醒来的天将指向天庭，师徒才知道黑印来自同一道敕令。悟空先清出有狼群的山路，其余三人护送百姓撤离，随后在沿途会合。他们一关一关打上天庭，击败受控的守将，寻找敕令源头。

到了无相天阙，四人击碎无相帝君手中的帝印，解开了牵在诸将身上的黑线。帝君清醒后，把护身日轮的残片交给唐僧。黑衣人带着铜印逃进裂隙，四人没能拦住他。

选择「再入轮回」后，四人追入裂隙。黑衣人倒转铜印，试图让敕令与天将一起回到被控制的开端，也抹去四人追查过的痕迹。日轮残片护住四人的记忆、修为与随身行囊，他们得以带着上一轮的成长重回山路。逆转时间的铜印也留住了历次施咒的余力，黑印逐轮加深，守将变得更难对付。

## 开场四页

| 页 | 画面 | 过渡 |
| --- | --- | --- |
| 01 | 天钟响起，黑衣人篡改敕令，受控的天将下界。 | 金色天钟、朱红飘带和三道朱痕引出控制的源头。 |
| 02 | 村民躲避天将与狼群，四人合力救援。 | 悟空看到天将颈后的黑线。 |
| 03 | 悟空卸去天将的武器，唐僧解除黑印。 | 恢复神志的天将指向天庭。 |
| 04 | 三人安顿百姓，悟空带金箍棒先入山林。 | 狼群伏在阶上，接入第 1 关。 |

## 轮回结尾四页

| 页 | 画面 | 过渡 |
| --- | --- | --- |
| 01 | 四人合击，帝印裂开，无相帝君与诸将恢复神志。 | 确认救援成功，幕后人仍在。 |
| 02 | 帝君交出日轮残片，黑衣人逃入裂隙，师徒追赶。 | 黑衣人手中是开场出现的三痕铜印。 |
| 03 | 铜印倒转，宫阙与落石逆流，日轮残片护住四人。 | 解释为什么重返起点仍保留成长。 |
| 04 | 天钟再响，四人经过系红绸的路碑，迎向山路。 | 回到第 1 关，四人知道该去哪里寻找黑印。 |

开场按 `Opening_01` 至 `Opening_04` 播放。终关胜利后点「再入轮回」时，按 `Ending_01` 至 `Ending_04` 播放，再进入新一轮第 1 关。轮回结尾已重现开场的天钟与路碑，接关时可直接用结尾末页过渡。
