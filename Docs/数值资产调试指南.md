# 数值资产调试指南

本次数值迁移以迁移前的预制体、脚本和技能总表为默认值，保留原玩法与存档格式。场景布局、Sprite 引用和关卡入口没有改动。

## 从这里开始

在 Project 中打开 **Assets/Projects/Resources/Balance/BalanceCatalog.asset**。总目录按四角色、小怪、Boss、投射物/特效、公共规则和关卡分组，点击引用即可打开对应配置。

每个 BalanceProfile 的 Inspector 支持按中文标签、组件名、字段或路径筛选。基础参数按组件和对象路径分组；招式与特殊机制展开后可查看值，鼠标悬停可见稳定键与来源位置。修改数值即可，不要改系统键和绑定路径。

## 常见调参位置

| 想修改 | 查找字段 / 分组 |
| --- | --- |
| 玩家、敌人基础 HP | 对应单位资产 → Health → 基础生命上限 beginBlood |
| 敌人经验 | 对应小怪/Boss 资产 → EnemyRewards → experienceReward |
| 普攻、组合技和近战伤害 | 对应单位资产 → 攻击箱路径下的 Attack / 基础伤害 |
| 远程招式伤害、范围、预警和持续时间 | 单位的招式/特殊机制参数，或关联投射物/区域资产中的 damage、duration、radius 等 |
| 走路、奔跑、后退、跳跃 | PlayerMovement / EnemyMovement 及具体派生移动组件 |
| 刚体重力、质量、阻尼 | Rigidbody2D 分组 |
| 本体、受击箱、检查箱的初始范围 | 对应 BoxCollider2D 路径的尺寸与偏移 |
| 最大蓝量、最大气力及跑跳消耗 | PlayerResources 分组 |
| 攻击增加的无双能量 | PlayerBoost → deltaBoost（每次有效命中） |
| 无双时长、能量上限、衰减及增益 | PlayerBoost 分组 |
| 暴击率、暴击伤害 | PlayerCombat 分组 |
| 四人各技能的学习/升级费用、蓝耗、冷却 | 各玩家资产顶部的“技能等级”表；levels 下标 0 是 1 级 |
| 普攻间隔、连击记忆时间、组合技气力消耗 | PlayerCombat / allAttacks 对应招式记录 |
| 敌人各招冷却、前摇、释放帧 | 对应 Combat 的 attackDelay、cooldowns、releaseFrames、windups 或特殊机制参数 |
| 攻击箱按帧开关 | AttackOpenIdx / AttackShutIdx 或具体招式的释放/采样帧参数 |
| 待机、攻击、受击、死亡播放速度 | 对应 Controller 中各 SpriteData 的 fps |

动态招式会在出招时调整攻击箱，运行中的范围以该招式参数为准；BoxCollider2D 分组保存初始范围。位置、朝向、计时以及结构性索引仍由状态机控制。平方距离判定保留原单位，例如 `sqrMagnitude` 对应的 36 表示 6u 的距离平方，来源提示会保留原表达式。

`SkillProgression` 对外接口不变，但优先读取四人各自资产内的技能表。旧 `Resources/Skills/SkillProgression.asset` 仅作缺少新配置时的兼容回退，日常不再修改它。技能表沿用原来的整数费用、蓝耗和冷却类型。

## 修改后如何生效

1. 修改对应 `.asset`，保存工程。
2. 重新进入关卡，或在训练场重新生成目标。玩家基础属性建议重新进入训练场，使四角色一起重新初始化。
3. 冷却、位移和无双等运行状态不会在切换角色/对象池回收时被配置强制清零。技能已开始的冷却仍按该次释放时的快照完成。
4. 基础属性先读取资产，随后叠加存档中的技能等级、临时增益、召唤倍率与轮回倍率。测试基础值请使用第 0 轮或训练场。

当前血量、当前蓝量/气力、当前无双能量、剩余冷却、已触发的 Boss 阶段、波次进度不属于设计配置，不会迁入资产。角色 ID、阵营/层掩码、状态枚举和数组结构也不会当作可随意改动的数值项。

预制体中的旧字段保留为兼容默认值，新 `.asset` 是实际数值来源。只改预制体旧字段通常不会覆盖已有资产；请从总目录修改。可以继续替换 Sprite 和调整位置；若重命名攻击箱、移动组件层级或更换组件类型，请运行资产校验，核对路径绑定。

## 新增与检查

- `Tools → 数值配置 → 补齐缺少的数据资产（保留已有调参）`：补齐新预制体、配置字段、目录和绑定，保留已存在的数值。
- `Tools → 数值配置 → 校验资产与预制体绑定`：在临时预制体内容中逐项应用并验证；不会保存这些临时实例。
- 新增平衡参数推荐使用有意义命名的 `[SerializeField]` 字段，再运行补齐工具。已有脚本常量的稳定键固定保留，不要重复运行本地一次性迁移器重排键名。

运行时使用 BalanceBinding，在其他组件初始化前应用基础参数。反射只用于初始化赋值；战斗期间读取字段或缓存字典。禁用/启用不重复应用，因此不会覆盖已缩放 HP、正在生效的增益或对象池本次生命的状态。敌人生成读取资产基础 HP，再按原流程计算倍率，避免从预制体旧值回退或重复乘算。

具体编译、实测和保护范围见 [迁移验收报告](数值资产迁移验收报告.md)。
