# 技能学习与等级配置

统一配置资源：`Assets/Projects/Resources/Skills/SkillProgression.asset`。技能界面和实际施法都读取这里，不需要在角色的 Combat 和 UI 中分别改数值。

- `maxLevel`：最高技能等级，当前为 6。
- `skills`：每项通过 `player` 和从 1 开始的 `skillNumber` 区分技能，当前四人各三项。
- 每项的 `levels` 数组第 0 项表示 **1 级**，第 1 项表示 **2 级**，依次类推。
- `goldCost`：购买这一等级所需金币。1 级是学习费用，2 级是从 1 升到 2 的费用。
- `manaCost`：技能处于这一等级时的施法蓝耗，当前用整数。
- `cooldown`：技能处于这一等级时的新一次施法冷却秒数，当前用整数。

例如要让悟空技能一升到 2 级时花费 200 金币，之后蓝耗 15、冷却 8 秒，找到 `player=WuKong, skillNumber=1` 的 `levels` 第 1 项，将三个字段设置为 `200 / 15 / 8`。

未学习是 0 级，界面预览 1 级属性、显示学习费并遮挡图标。学习后显示当前等级属性和下一级的升级费。满级后升级按钮禁用，费用显示为 0。已经开始的冷却保留当次长度，升级不重置现有冷却，下一次施法使用新等级属性。

新增存档和直接运行场景创建的临时数据默认有 10000 金币，技能全部未学；已有存档继续使用原金币和技能等级。调整初始金币修改 `SaveData.InitialGold`，不会重复给已有存档补钱。学习、升级和金币变更先暂存在 `GameSession`，只有地图的“保存游戏”以及关卡胜利、失败自动保存会写盘。返回地图保留这次未保存的数据；返回主菜单则丢弃未保存修改，恢复上次存档。直接运行场景且未选存档时只保留内存数据。

提高等级上限时，同时补齐各技能的 `levels`。新增技能时添加对应的配置项，并配置角色战斗招式与界面，存档技能数组支持扩充。费用等数字超过现有位数时，界面会复用原数字样式补充位数；冷却的秒单位图片保留。
