## 实际接入

- `BalanceProfile`：按组件路径保存有类型的设计参数及稳定键常量，包含角色技能等级表与关联效果入口。
- `BalanceBinding`：提前于角色/敌人的普通 Awake 读取基础值；只初始化一次，禁用/启用不重复覆盖运行状态。
- `BalanceRuntime`：角色、类型和常量键查找缓存；公共基类参数按声明类正确解析，派生角色也能读取公共资产。
- 敌人生成从资产读基础 HP，再走原有召唤/轮回缩放；对象池预热时先应用基础数据，再允许 Launch 配置本次投射物状态，避免第一次启用覆盖运行参数。
- 关卡参数在波次倍率准备前读取，仍由原关卡流程生成与结算。原有整关取整、最大余数分配及轮回封顶默认值保持。
- Inspector 增加分类、搜索、中文常用字段标签、原始路径与表达式提示。总目录按分类引用全部 BalanceProfile，角色还能直接打开关联特效资产。
- 生成工具只补缺项和绑定，保留已有调参值；场景参数导出使用预览场景，不保存正式场景。

完整新增资产、修改脚本和预制体列表见 [delivery-manifest.json](../output/BalanceAudit/delivery-manifest.json)。本地迁移备份在 `output/BalanceAudit/before/`，原文件未删除，没有 git commit。
