## Unity 导入与切片

- 已附每张 PNG 对应的 `.meta`，设置为 `Sprite (2D and UI)` / `Multiple`，包含 16 个固定矩形切片。
- 子精灵名为 `动作名_01` 至 `动作名_16`，例如 `Idle_01`，序号与时间顺序一致。
- 统一 `Pixels Per Unit = 100`，`Full Rect`，双线性过滤，关闭 Mip Maps，Clamp，关闭纹理压缩；最大纹理尺寸 2048，不做 NPOT 缩放。
- 落地基线为单元格左上坐标 `y=328`。统一自定义 Pivot 为 `(0.5, 0.14583333)`，对应从底部起 56px 的固定地面锚点。
- 如需手动重新切片，选择 `Grid By Cell Size = 256×384`，Offset/ Padding 均为 0，保持上述 Pivot；不要使用自动紧边裁剪。
- 跃起高度已包含在 `LeapSlam` 图像中；所有帧使用同一锚点，不能逐帧按图像底边重新贴地。
- `Idle`、`Walk` 设为循环。其余动作播完一次；`Death` 停在第 16 帧，不接回待机。

## 动作分段备注

### Idle / 待机呼吸

F01 静立持锤；F02–05 吸气抬肩、盔缨摆动；F06–09 呼气放松握柄；F10–13 重心回落；F14–16 收回初始姿势。F16 与 F01 像素一致。

### Walk / 重步行走

F01 左脚落步；F02–04 下沉承重；F05–08 右腿前摆；F09 右脚着地；F10–12 再次下沉；F13–16 左腿回摆并闭合循环。F16 与 F01 像素一致。

### HammerSweep / 横向锤扫

F01–05 扭身蓄力、举锤至右肩后；F06–09 横扫；F10–12 随势压低锤头；F13–16 收锤回到公共待机姿势，末段短暂停稳。

### LeapSlam / 跃起重砸

F01–04 下蹲蓄力；F05–08 双脚离地、举锤；F09–11 下砸并落地；F12–14 冲击深蹲；F15–16 起身回待机。离地偏移已经绘入单元格，播放时不要再逐帧贴地。

### GroundPound / 原地砸地

F01–05 举锤伸展；F06–08 向下重砸；F09–11 深蹲触地；F12–16 缓慢起身并回公共待机。

### Hit / 受击后仰

F01 准备姿势；F02 肩部受击；F03–06 上身向画面右侧后仰；F07–09 吸收冲击；F10–13 站直；F14–16 复原。F16 与 F01 像素一致。

### Death / 死亡倒地

F01–03 后仰失衡、松开一手；F04–07 屈膝；F08–11 跪地支撑；F12–15 向前侧倒；F16 保持倒地终态。播放后停在 F16，禁止循环。
