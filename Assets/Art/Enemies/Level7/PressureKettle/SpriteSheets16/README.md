## 图像与 Unity 切片

- 7 张 RGBA 真透明 PNG，统一 1024×1536，4 列×4 行，每格 256×384，每张 16 帧，共 112 帧。
- 帧序从左到右、从上到下。每帧角色、完整壶嘴、提柄、壶盖与短肢都包含在本格内；死亡时另计脱落壶盖。
- 每帧 alpha 范围不超过 178×288（格宽 70%、格高 75%），左右至少 32px、上下至少 40px 空透明边距。
- 固定格内地面基线 y=328（左上为原点）。所有切片使用 Pivot=(0.5,0.145833333)，PPU=100；弹跳只改变格内离地偏移，不改变切片或 Pivot。
- 每张 `.meta` 已包含 16 个 Sprite / Multiple 固定矩形切片，名字为动作名_0 至 _15。Full Rect、Bilinear、Clamp，关闭 Mip Maps 与纹理压缩。
- 手动重切使用 Grid By Cell Size=256×384、Offset=0、Padding=0，保持统一 Pivot；不要按各帧紧边自动裁剪。
- Idle、Walk、Hit 的 F16 与 F01 像素一致；SteamJet、PressureBomb、PressureRelease 的 F16 接公共 Idle_0；Death 保持侧倒熄火终态。
- 只画机械壶身、实体零件与内部炉光。没有蒸汽、烟、炸弹、火焰、冲击波、外部粒子或动作线。
- PressureBomb 的投掷手为空，打开的壶盖仍通过铰链连接；Death 的脱落盖作为同一帧装备保留，不被当噪点删除。
- 投掷组已重做以保持画面左侧弯壶嘴始终可见；Death F09/F10 的漏盖用同组 F08 完整脱落盖补回，保持相同尺度并连续下落。

## 动作分段备注

### Idle / 待机呼吸

F01 准备姿势；F02–05 炉门增亮、壶盖略抬；F06–09 壶身回落、壶嘴略低；F10–13 小臂与排压栅微动；F14–16 回到 F01。双脚不迈步。

### Walk / 摇摆行走

F01 左脚在前；F02–05 向左腿滚动承重；F06–09 右腿经过；F10–13 右脚落地、壶身轻弹；F14–16 左腿回摆并闭合循环。

### SteamJet / 蒸汽喷射姿势

F01–04 后仰抬壶嘴；F05–07 炉门增亮并向前猛倾；F08–12 保持喷射支撑姿势；F13–16 收回准备。壶嘴为空，不画蒸汽。

### PressureBomb / 压力炸弹投掷姿势

F01–04 蓄势下蹲、开盖；F05–08 短腿弹起并完全开盖；F09–12 空手投掷；F13–15 后坐、落地收盖；F16 回到待机。离地高度已绘入单元格。

### PressureRelease / 过压泄放姿势

F01–04 炉门与盖缝升温；F05–07 掀盖展臂；F08–11 后仰、壶嘴上指；F12–15 收盖降温；F16 回到待机。高亮只在眼睛、炉门和盖缝内部。

### Hit / 受击摇晃

F01 准备；F02 壶盖弹动；F03–06 向画面右侧后仰；F07–09 短腿摇摆吸收冲击；F10–13 站稳；F14–16 回到 F01。

### Death / 泄压熄火倒地

F01–03 脱盖侧倾；F04–07 腿部失力、炉火变暗；F08–11 侧倒，壶嘴靠地；F12–15 提柄变形、余热熄灭；F16 停在侧倒终态。脱落壶盖与本体一起保留在各自单元格中。
