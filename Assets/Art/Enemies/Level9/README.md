## 与已有小怪的区分

已核对当前工程的刀兵、毒箭射手、盾兵、隐身飞轮、锁链牵引、爆破灯笼/标记/射线、青锤冲击波、落锤与战旗增益。
本组的主要战斗判断分别是“何时离开窄切面”“先破哪个可破坏界楔”“何时起跳/落地或打断换位”。不以射箭、飞轮往返、落锤、插旗加攻或大范围地面长波作为主招。
空间换位采用清晰双锚预告，不采用长时间隐身追踪背刺；镇卫的重玺只做近身错拍，封路效果来自可破坏界楔，不是举盾减伤；织使改变高低空间与既有单位站位，不追加召唤物或团队攻击增益。

## 组合与公平性

- 建议先让玩家分别遇到单种，再混编刃侍+镇卫、刃侍+织使，最后少量三者同场。
- 同时最多一组强空间封锁：门阙挤压与反相织域不能同时覆盖玩家，避免一边被迫跳跃、一边被高层必杀。
- 换位与区域效果均在起手时确定位置，不持续跟踪；红色代表真正伤害，金色只作预警。
- 界楔可破坏、可越过，不能在玩家体内生成完整牢笼；打断或击破都应提供反打窗口。
- 每种小怪只占 boss 一部分能力。帝印全域镇压、完整空间封锁与第二阶段面具破裂/日轮展开留给无相帝君。
- 攻击裂隙、界楔预告、高低空间域和易位连线后续均做独立特效，不烘焙进角色本体动画。
