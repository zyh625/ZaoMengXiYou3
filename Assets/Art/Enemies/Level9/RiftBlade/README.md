# 裂隙刃侍 / RiftBlade

定位：敏捷近战 / 延时切片 / 双锚换位。

前倾低重心，兜帽与裂纹白面，短甲分摆，双手各执一柄由残缺日轮制成的短柄弧刃。黑色占比最高，轮廓横向展开。

## 折隙双斩 / 基础近战

双弧刃先低扫再斜切，第二击只向前补一小步；刀刃不脱手、不发飞轮。

预警：交刃蓄势约 0.35 秒，第二击间隔约 0.25 秒。

反制：第一击后穿身或退到刀尖外；第二击落空后有约 0.45 秒硬直。

## 留痕合刃 / 延时空间切片

挥刃在前方固定位置留下窄竖折痕，约 0.7 秒后折痕合拢，仅结算一次；折痕不会追踪玩家。

预警：先出现无伤害的细金折线，再转为清晰红色刃口。

反制：看到金线后离开该窄面，或穿过近身空档打断本体；不是圆形标记爆炸。

## 双锚换位 / 站位扰动

在自身两侧留下两个可见锚点，约 0.8 秒蓄势后沿既定两点换位；到达后短暂停顿，不能瞬移即命中。

预警：两个落点同时显形，转移方向由举起的弧刃指示。

反制：预判已标出的落点；起手与落点均可受击，不获得长时间隐身或无敌。

## 弱点

留痕与换位被打断时进入短暂裂面失衡；依靠预警与节奏，而不是闪现到背后强制命中。

## 后续动画建议

Idle, Walk, FoldDoubleSlash, SeamCollapse, AnchorSwap, Hit, Death

## 独立特效建议

延时折痕、双锚换位预警、短距离换位残影。特效不画进本体待机形象图。
