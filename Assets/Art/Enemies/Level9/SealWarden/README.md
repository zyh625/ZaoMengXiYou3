# 缄印镇卫 / SealWarden

定位：重装压阵 / 可破坏界楔 / 路线挤压。

宽方肩、下沉头位、三道红裂白面、两枚黑金重玺拳套；背部两条长方界碑可展开为封路界楔。轮廓方重，饰金比例较高。

## 双玺错打 / 重装近战

左右重玺错拍短打，第一击推开身前目标，第二击打固定前方范围；不产生地面长波或落锤。

预警：对应拳套先上抬，约 0.55 秒后出第一拳。

反制：绕背或在两拳间退开；没有举盾免伤或全角度反击。

## 立界双楔 / 可破坏空间地形

在前方两个预告位置立起低矮界楔，保留中间通路；每人最多一对，建议存续约 3 秒，可用攻击击碎，也可越过。

预警：约 1 秒地面轮廓预警；不在玩家脚底或已占据的位置强行生成。

反制：打碎任一界楔或跳过；不形成不可逃脱的完整牢笼。

## 门阙挤压 / 一次性路线收紧

仅在双楔存在时使用；两楔约 0.8 秒预警后缓慢内收一次，目标区固定，不追随玩家，不连续结算接触伤害。

预警：两楔的金边同步转红，本体双拳合拢蓄势。

反制：起跳越过低楔，或击碎任一楔取消收拢并使镇卫硬直。

## 弱点

界楔是可攻击的副目标；被破坏时镇卫会失衡。威胁来自有限的场地重排，不靠厚盾、冲击波或全场增益。

## 后续动画建议

## 独立特效建议

界楔落位预告、独立可破坏界楔、门阙内收提示。特效不画进本体待机形象图。
