# 倒相织使 / PhaseWeaver

定位：高低空域交替 / 区域反相 / 队友易位。

修长悬浮身形，象牙白长袍与黑色内衬，半月眉冠、偏置残轮；左右分别托起黑梭与白梭，双梭明暗对应两种空间状态。

## 阴阳分层 / 可读的高低切换

黑梭举起时只攻击预告区域的低层，白梭举起时只攻击其高层；每次施放交替，不发射普通飞弹。

预警：对应梭与区域轮廓提前约 0.7 秒亮起；金色只预告，红色才是有效伤害。

反制：低层用起跳越过，高层保持落地；区域在起手时锁定，随后不追踪。

## 反相织域 / 双拍区域节奏

在同一小范围内先结算一次低层或高层，再于约 0.9 秒后反转为另一层；总计两拍，不无限维持。

预警：梭的黑白次序和地面双段提示提前给出，不靠真假难辨的隐形判定。

反制：离开区域、按顺序跳起/落地，或打断本体；不封死整张屏幕。

## 易位敕令 / 阵型重排

与附近一名同阵营小怪连线蓄势约 1 秒，随后交换双方站位；只交换现有单位，不召出新怪，不回血或加攻。

预警：两端位置和交换连线都可见，不能将单位换进玩家碰撞体内。

反制：优先打断织使；交换后两者均有短恢复窗口。

## 弱点

低耐久，施法期间移动很慢；玩家可读双梭颜色与抬手方向。它制造行动节奏与站位变化，不承担插旗增益或落锤输出。

## 后续动画建议

IdleHover, Glide, LowPhaseCast, HighPhaseCast, InvertField, AllyExchange, Hit, Death

## 独立特效建议

高低层区域预告、反相域、易位连线与落点提示。特效不画进本体待机形象图。
